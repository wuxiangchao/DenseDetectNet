#### **1 、项目概述**

本项目实现了一个名为`D2Net`的端到端深度学习框架，用于从稀疏的激光雷达(`LiDAR`)点云数据中同时执行点云稠密化和3D目标检测两项任务。

本项目采用多任务学习范式，核心设计思想是以鸟瞰图(`BEV`)为中心进行高精度目标检测，并利用其丰富的语义特征来引导和增强三维空间中的点云稠密化。这种设计让两个任务相互促进，在提升检测精度的同时，生成以物体为中心、集合细节更丰富的高质量稠密点云。

**主要特性**

* **先进的联合训练架构** : 采用3D U-Net结合2D BEV FPN的结构，有效平衡并处理检测和稠密化两个任务。
* **高性能检测器** : 基于类CenterPoint的无锚框（Anchor-Free）范式，并使用IoU-based损失函数，以获得更精确的定位。
* **高质量稠密化** : 稠密化头在局部坐标系下预测点云片，由逐体素的Chamfer Loss监督，学习目标更稳定，细节恢复更清晰。
* **高效的数据流水线** : 采用Numba JIT对CPU密集型的体素化过程进行加速，显著提升数据加载速度。
* **灵活的两阶段训练策略** : 支持解耦任务学习，可先专注训练检测，再利用学到的强大特征来训练稠密化，提高了训练的稳定性和最终性能。

#### **2、核心设计思路**：

构建一个多任务学习网络，该网络拥有一个共享的骨干网络，用于从稀疏点云中提取语义特征。
然后，这些特征被送到两个不同的任务头(`Head`):

> * **稠密化头**： 该模块按生成器设计，负责预测并生成新的点，以填充稀疏点云中的空洞，使其变得稠密。
> * **目标检测**： 一个技术中心的`Anchor-Free`检测头，负责在特征图上定位物体中心、预测其`3D`尺寸和方向。

该端到端的网络架构允许两个任务相互促进，设计的稠密化模型可以为检测提供更丰富的特征，而检测任务的监督信号可以引导骨干网络学习对物体更有辨识度的特征。

#### **3、数据预处理流程**

本项目使用`KITTI`数据集。数据处理流程是模型性能的基石，主要包含体素化、坐标系变换和真值（`Ground-Truth`）生成三个阶段。

* **3.1 点云体素化 (`pointcloud_utils.py`)**
  * **输入** : 原始LiDAR点云 (`.bin` 文件, `(N, 4)`: x, y, z, intensity)。
  * **过程** :
    1. **范围过滤** : 根据 `d2net_kitti.yaml` 中定义的 `point_cloud_range` 对点云进行裁剪，移除范围外的点。
    2. **体素化** : 将裁剪后的点云划分为固定大小的3D体素网格（Voxel Grid）。
    3. **性能优化** : 为了加速这个计算密集型过程，我们使用 **Numba** 的JIT（Just-In-Time）编译器对核心的体素化循环进行了优化，将原始的Python循环编译为高效的机器码，极大地提升了数据加载速度。
  * **输出** :
    * **体素特征** : 每个非空体素内所有点的坐标和强度均值。
    * **体素坐标** : 每个非空体素在3D网格中的 `(z, y, x)` 整数坐标。
    * **稠密化真值** : 每个非空体素内部包含的真实点云坐标 `(M, T, 3)` 及其掩码，其中M为体素数量，T为体素内最大点数。
* **3.2 坐标系变换 (`kitti_utils.py`, `kitti_dataset.py`)**
  * **问题** : KITTI数据集的点云在**激光雷达坐标系**下，而3D标注框在**相机坐标系**下。这两个坐标系定义不同，直接使用会导致模型学习到完全错误的物体位置和姿态。
  * **解决方案** :
    1. **加载标定文件** : 为每个样本加载其对应的 `calib/*.txt` 标定文件。
    2. **坐标变换** : 使用标定矩阵（`R0_rect`, `Tr_velo_to_cam`），将每个标注框的中心点坐标从相机坐标系精确地转换到激光雷达坐标系下。
    3. **角度变换** : 同时，将相机坐标系下的Y轴旋转 `rotation_y` 转换为激光雷达坐标系下绕Z轴的旋转 `yaw`。其数学关系为：
       $yaw_{lidar}=−(rotation_{y_{camera}}+\frac{\pi}{2})$
* **3.3 真值目标生成 (`kitti_dataset.py`)**
  * **检测目标** :
    * **热力图 (Heatmap)** : 这是一个2D概率图，其尺寸与模型BEV输出特征图一致。在每个物体的真实中心点位置，我们绘制一个二维高斯分布“热点”，其值为1，向外逐渐衰减。
    * **回归目标** : 对于每个“热点”位置，模型需要回归8个参数：中心点的局部偏移 `(dx, dy)`，物体底部的`z`坐标，物体尺寸的对数 `(log(l), log(w), log(h))`，以及正确转换后的朝向角 `(sin(yaw), cos(yaw))`。
  * **稠密化目标** :
    * 将每个体素包含的真实点云，减去该体素的几何中心点坐标，得到一组 **局部偏移量** 。模型将被训练来直接预测这些归一化的局部偏移，而不是在世界坐标系下的绝对位置，这大大降低了学习难度，提升了训练稳定性。

#### **4、网络架构概述**

模型采用端到端的可微网络结构，由`3D U-Net`骨干、`2D BEV`骨干和两个任务头组成。

* **4.1 3D U-Net 骨干网 (`backbone.py: UnifiedBackbone`)**
  * 这是一个基于3D稀疏卷积的编码器-解码器（Encoder-Decoder）结构。
  * **编码器** : 包含4个下采样模块，逐步提取点云特征并减小空间分辨率。
  * **解码器** : 包含4个上采样模块，通过转置稀疏卷积和跳跃连接（Skip Connections）逐步恢复空间分辨率。
  * **双重输出** :
    1. **瓶颈特征 (`bottleneck_features`)** : 从编码器最深处输出，包含了最丰富的场景级高级语义信息，用于后续的BEV感知。
    2. **最终3D特征 (`final_3d_features`)** : 从解码器最终端输出，其空间分辨率和体素索引与输入完全对应，保证了与稠密化真值的一一匹配，用于稠密化任务。
* **4.2 2D BEV 骨干网 (`bev_backbone.py: BEVBackbone`)**
  * **输入** : 将3D U-Net的瓶颈特征沿高度（Z）维度压缩，形成一个多通道的BEV特征图 `(B, C*Z, H, W)`。
  * **结构** : 一个轻量级的特征金字塔网络（FPN），包含下采样和上采样路径，用于深度处理BEV特征，并融合多尺度信息。
  * **输出** : 一个信息量更丰富的增强版BEV特征图，用于后续的目标检测。
* **4.3 检测头 (`detection.py: DetectionHead`)**
  * 一个简洁高效的卷积头，接收来自2D BEV骨干网的增强特征。
  * 通过共享卷积层和最终的1x1卷积层，输出一个单一的预测张量，其通道维度包含了所有类别的热力图和8个回归参数。
* **4.4 稠密化头 (`densification.py: DensificationHead`)**
  * 一个轻量级的MLP网络。
  * 接收来自3D U-Net解码器末端的、与输入体素一一对应的3D特征。
  * 为每个输入的非空体素预测一个包含N个点的“点云片”的**局部偏移量** `(N, 3)`。

#### **5、损失函数设计(`loss.py`)**

总损失是检测损失和稠密化损失的加权和：

$L_{total}=λ_{det} \dot L_{det}+λ_{dense} \dot L_{dense}$

* **4.1 检测损失 ($L_{det}$)** :
  * **分类损失** : 使用 **Focal Loss** 来处理热力图中的正负样本极度不平衡问题。
    $FL(p_t)=−\alpha_t(1−p_t)^{\gamma} \log (p_t)$
  * **回归损失** : 采用复合损失来提升定位精度。
    * **BEV IoU 损失** : 对预测框和真值框在鸟瞰图下的IoU进行监督。我们采用旋转框的轴对齐包围盒来近似计算IoU，以保证稳定性和效率。
      $L_{IoU}=1-IoU_{BEV}$
    * **Z轴与高度L1损失** : 对`z`坐标和物体高度`h`使用L1损失进行直接监督。
      $L_{Z,H}=\left\|z_{pred} - z_{gt} \right\| + \left\| h_{pred} - h_{gt} \right\|$
    * 总回归损失由这两部分加权构成：$L_{reg}=\omega_{iou} \dot L_{IoU} + \omega_{z,h} \dot L_{Z,H}$
* **4.2 稠密化损失 ($L_{dense}$)** :
  * 使用 **Chamfer Distance** 来衡量预测的点云片和真实的局部偏移点云片之间的差异。
    $L_{CD}(S_1,S_2)=\sum_{x \in S_1} \min_{y \in S_2} \left\|x-y\right\|_2^2 + \sum_{y \in S_2} \min_{x \in S_1} \left\|x-y\right\|_2^2 $

    这里的 $S_1$ 是预测的局部偏移， $S_2$ 是真实的局部偏移。

#### **7、调优策略**

* **7.1 两阶段训练 (`train.py`)** :
  为了解决多任务学习中的任务干扰问题，我们采用了一个灵活的两阶段训练策略：
  * **第一阶段 (`--stage 1`)** : 设置 `dense_weight: 0.0`，只训练目标检测任务。目标是让共享的3D U-Net骨干学会提取对检测有用的高级语义特征。
  * **第二阶段 (`--stage 2`)** : 加载第一阶段的权重，并冻结除`DensificationHead`外的所有网络层。然后只训练稠密化任务。目标是利用已经训练好的高质量特征来学习精细的几何重建。
* **7.2 性能优化** :
  * **自动混合精度 (AMP)** : 在 `train.py` 中使用 `torch.cuda.amp.autocast` 和 `GradScaler`，利用RTX 3090的Tensor Cores进行FP16计算，显著提升训练速度并降低显存占用。
  * **数据加载优化** : 使用 **Numba** 加速体素化；在 `DataLoader` 中设置合适的 `num_workers`；将数据集存储在SSD上。
* **7.3 调参与实验方法** :
  * **快速验证** : 在修改代码后，先在**单个批次上进行过拟合**测试，确保损失能快速下降，验证代码逻辑的正确性。
  * **快速迭代** : 创建一个“迷你”数据集（例如`train_mini.txt`），在小数据集上快速进行实验和A/B测试，验证新想法的效果。
  * **实验监控** : 使用 **TensorBoard** 可视化和监控训练过程中的所有损失曲线和学习率变化，用于对比实验和提前发现问题。
  * **关键超参数** :
    * `learning_rate`: 学习率。
    * `batch_size`: 批次大小，应在显存允许下尽可能设大。
    * `dense_weight`: 第二阶段训练中稠密化任务的权重，用于控制稠密化效果的强度。
    * `iou_loss_weight`, `l1_loss_weight`: 用于平衡回归损失内部不同分量的权重。

##### **8.4. 使用方法**

###### **1 训练 (Training)**

本项目采用两阶段训练策略，通过命令行参数控制。

* **第一阶段: 专注训练目标检测**
  此阶段将禁用稠密化损失，让骨干网络集中学习检测所需的语义特征。
  **Bash**

  ```
  python train.py --stage 1
  ```

  训练完成后，会在 `checkpoints/` 目录下生成类似 `d2net_stage1_epoch_XX.pth` 的模型文件。
* **第二阶段: 冻结骨干，训练稠密化**
  此阶段加载第一阶段的权重，冻结大部分网络，只训练稠密化头。
  **Bash**

  ```
  # 将 d2net_stage1_epoch_XX.pth 替换为您第一阶段保存的最新模型
  python train.py --stage 2 --load_from checkpoints/d2net_stage1_epoch_XX.pth
  ```

  最终生成的 `d2net_stage2_epoch_XX.pth` 是您功能完整的最终模型。

###### **2 实验监控 (Monitoring)**

脚本集成了TensorBoard。在开始训练后，在项目根目录下打开一个新终端，运行：

**Bash**

```
tensorboard --logdir=runs
```

然后在浏览器中打开 `http://localhost:6006/` 即可实时查看损失曲线等指标。

###### **3 推理与可视化 (Inference & Visualization)**

1. 打开 `inference.py` 文件。
2. 修改 `model_path` 变量，使其指向您第二阶段训练完成的模型权重文件。
3. 修改 `sample_id` 变量，选择您想可视化的验证集样本。
4. 运行脚本：
   **Bash**

   ```
   python inference.py
   ```

   将会弹出一个Open3D窗口，展示原始点云（灰色）、稠密化后的点云（蓝色）以及3D检测框。

### 增加点云补全的一些思考？

#### **核心挑战**

> 在现有模型的基础上增加一个点云补全功能，并不容易，点云补全与上诉实现的点云稠密化具有本质的区别，点云稠密化是在已知几何的基础上进行插值和加密，而点云补全则需要模型根据先验知识进行推理和生成，这是两个不同层面的任务。

在现有的`D2-Net`的架构基础上，从点云稠密化升级到点云补全是一项系统工程，而非简单的模块添加。稠密化是在可见表面上增加点，而补全则需要根据物体的部分观测，推理并生成其被遮挡或未扫描到的结构。这要求模型具备关于物体完整形态的形状先验知识。


| 功能     | 点云稠密化(已实现) | 点云补全(新目标)              |
| ---------- | -------------------- | ------------------------------- |
| 任务     | 在可见表面上增加点 | 生成不可见的部分(如车顶)      |
| 本质     | 几何插值           | 基于先验知识的形状生成        |
| 所需信息 | 局部的几何细节     | 全局的、关于"Shape"的形态概念 |

因此，简单的修改现有的模块是无法完成这个任务的，需要引入一个全新的模型来提供关于形态的先验知识。

#### 实现方法：引入形状先验的生成式框架

> 初步设想： 引入一个**"形状先验(Shape Prior)"**，通过一个预训练的生成模型来实现，将整个过程分为以下两部分来实现:



**第一阶段**：须训练一个形状自编码器(Shape Autoencoder)
这个阶段的目标是训练一个专门的、能理解和生成完整汽车模型的独立网络。

1. 数据集：`ShapeNetCore.v2`
2. 自编码器网络设计:
   * **编码器(Encoder)**：接收一个完整的汽车点云，并将其压缩成一个低维的特征向量(Latent Code), 用这个向量描述这辆车的核心形状信息。
   * **解码器(Decoder)**: 接收一个形状编码向量，将其解压缩，生成一个完整的高分辨率的汽车点云。
3. 预训练
   * 在`ShapeNet`的汽车数据集上训练这个自编码器。训练完成后，这个解码器具有汽车生成功能，给他一个形状编码，能生成一辆完整、高质量的汽车。

**第二阶段**： 集成形状先验到`D2-Net`中

1. 架构修改

   * 移除稠密化头
   * 新增“形状编码预测头”：这是一个新的网络模块，与现有的`DetectionHead`并行，接收来自BEV骨干网络的特征，输出不再是之前的点云偏移，r而是预测每个被检测到的物体的形状编码(一个`128`维的向量)。
2. 推理流程设计

   * 检测：D2-Net照常运行，检测到一个物体，并预测出它e的`3D`边界框(位置、尺寸、姿态)
   * 预测形状：新的形状编码预测头会为这个物体预测出一个`128`维的形状编码。
   * 生成完整形状：将预测出的形状编码输入到u训练好并冻结权重的自编码器的解码器中，生成器会生成一个标准姿态下的完整汽车点云。
   * 放置到场景中：最后、利用第一步中检测框预测出的位置、尺寸和姿态信息，对这个生成的汽车点云进行旋转、缩放和评议，将其精确地放置到场景中的正确位置。
3. 新的训练目标(损失函数设计)

   * 在训练时，先将场景中每个真实汽车的残缺点云送入到预训练好的mi编码器，得到一个“伪真值”的形状编码。
   * 损失函数的目标：让形状编码预测头预测出的编码，与“伪真值”的编码尽可能接近。
